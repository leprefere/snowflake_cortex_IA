#  Coffee Shop AI Analytics with Snowflake Cortex

This project demonstrates how to build an **AI-powered analytics platform** using Snowflake Cortex.

It combines:
-  Cortex Analyst (Natural Language → SQL)
-  Cortex Search (Semantic Search)
-  Cortex Evaluation (AI reliability & validation)

---

##  Overview

The goal of this project is to explore how AI can:
- Translate business questions into SQL queries
- Execute queries directly in Snowflake
- Validate and evaluate AI-generated results

We simulate a real-world use case using a Coffee Shop dataset.

---


##  Features

### 1. Cortex Analyst (AI SQL Generation)
- Ask questions in natural language
- Generate SQL queries automatically
- Execute queries in Snowflake

 Example:
> "Top selling products"

---

### 2. Cortex Search (Semantic Search)
- Search products using natural language
- Based on product descriptions
- Uses vector-based retrieval

 Example:
> "chocolate dessert"

---

### 3. Cortex Evaluation (AI Validation)
- Compare generated SQL with expected SQL
- Execute both queries
- Measure accuracy

---

##  Dataset

The dataset includes:

- `customers`
- `products`
- `categories`
- `orders`
- `order_items`

It allows simulation of real business questions:
- Revenue analysis
- Product performance
- Customer behavior
